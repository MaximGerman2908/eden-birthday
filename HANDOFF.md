## 1. Executive Summary & Architecture

The application is a bespoke, high-craft, mobile-first web experience designed for Dandan's birthday. It balances playful cutesy aesthetics (sheep, capybaras with oranges, camels, and warm pastels) with reactive physics, 3D card tilt, an HTML5 scratch card, client-side calendar export, and an interactive itinerary.

### Technology Stack
- **Core Framework:** React 19 (`react`, `react-dom`) + TypeScript 5.7
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS 3.4 (`postcss`, `autoprefixer`)
- **Animation & Motion:** Framer Motion (`framer-motion` v12)
- **Effects:** `canvas-confetti` + custom HTML5 `<canvas>` layers
- **Icons:** `lucide-react`
- **Typography:** Google Fonts: *Varela Round* (friendly rounded Hebrew headings) & *Rubik* (legible UI body text)
- **Deployment:** GitHub Pages via `gh-pages` branch

## 3. Key Components & Implementation Details

### A. Ambient Hero & Bouncing Trio (`HeroGreeting.tsx`)
- **Visuals:** Features an animated bouncing trio: Sheep 🐑, Capybara with an orange 🦫🍊, and festive Camel 🐪.
- **Typography:** Uses clean, bold Hebrew typography without spellcheck-like squiggly underlines.
- **CTA Button:** Styled with high-contrast rich coral (`bg-[#E25530]` with `#D54521` border) and crisp white text (`font-extrabold`), ensuring readability on any display.

### B. 3D "Golden Ticket" VIP Pass (`GoldenTicket.tsx`)
- **Tilt Mechanics:** Computes mouse pointer delta relative to card bounds (`useMotionValue`, `useSpring`) with safe clamping (-7° to 7°).
- **RSVP Flow:**
  - Clicking *"ברור שאני באה! 💖"* fires pastel confetti, confirms reservation status, and unlocks calendar options.
  - **Calendar Export:** Calls `downloadIcsFile()` to generate an RFC 5545 `.ics` file with UTF-8 Hebrew characters and pre-configured reminders (3 hours prior), plus a Google Calendar URL.
- **Truly Unpressable Decline Button:**
  - Listens to `onMouseEnter`, `onPointerDown`, and `onTouchStart`.
  - When the cursor or finger approaches, it dynamically shifts 130px–210px in a random vector *before* the click can register.
  - Features dynamic text progression as she chases it (*"אופס! ברחתי 💨"*, *"עדיין מנסה?! 😂"*, *"הקפיברה לא מרשה 🦫"*).
  - Displays a live counter of thwarted decline attempts.

### C. Capybara Scratch Card (`ScratchCard.tsx`)
- **Canvas Implementation:** Uses HTML5 `<canvas>` with `globalCompositeOperation = 'destination-out'` to simulate real foil scratch-off.
- **Touch & Mouse Support:** Handles mouse events alongside touch events (`e.touches[0]`) with `touch-none` CSS.
- **Threshold Detection:** Samples pixel alpha transparency every 8 pixels. When transparency exceeds 40%, it automatically reveals the secret culinary intel and fires confetti.
- **Replay:** Includes a *"שוב 🦫"* reset button.

### D. Mystery Itinerary & Countdown (`MysteryItinerary.tsx`)
- **Timeline:** Vertical dashed line with animal emblems corresponding to each phase.
- **Locked Milestones:** Blurred teaser card with an encrypted padlock badge.
- **4-Column Clock Grid:** Responsive grid displaying Days, Hours, Minutes, and Seconds in individual boxes. Values are stacked (number above label) to prevent text clipping or horizontal overflow in RTL.

## 4. Configuration Guide (`src/data/birthdayConfig.ts`)

To customize any part of the evening, edit `src/data/birthdayConfig.ts`.

### How to Reveal the Mystery Restaurant
Change `venueStatus` from `"mystery"` to `"revealed"`:
```typescript
ticket: {
  // ...
  venueStatus: "revealed",
  venueName: "מסעדת שף מהממת",
  venueAddress: "רחוב הירקון 123, תל אביב",
  venueMysteryClue: "שולחן שף אינטימי שהוזמן מראש",
}
```

### How to Unlock Itinerary Items
Change `status` from `"locked"` to `"unlocked"`:
```typescript
{
  id: "step-4",
  time: "23:45",
  title: "מבצע סודי: משאלת חצות 🎂",
  description: "פרטי ההפתעה שמתגלים עכשיו!",
  status: "unlocked", // Changed from "locked"
  animal: "cake",
  badge: "נחשף!",
  locationName: "הספוט הסודי שלנו",
}
```

## 5. Operations & Deployment Runbook

### Prerequisites
- Node.js >= 20
- npm >= 10
- Git authenticated to GitHub

### Local Development
```bash
# Start Vite development server on port 5173
npm run dev

# Run TypeScript checks and build production bundle
npm run build

# Preview production build locally
npm run preview
```

### Deploying Changes to GitHub Pages
To publish changes to the live site at `https://maximgerman2908.github.io/eden-birthday/`:
```bash
npm run deploy
```
This runs `npm run build`, compiles the assets into `dist/`, and uses `gh-pages` to force-push the bundle directly to the `gh-pages` branch on GitHub. Updates reflect within 30–60 seconds.
