# 🐑🦫🐪 יום הולדת שמח עדנוש! (Eden's Birthday Invitation)

אפליקציית ווב מתוקה, חמודה ומלאת אהבה לכבוד יום ההולדת של עדן.
כוללת כבשים צמריריות 🐑, קפיברות רגועות עם תפוז על הראש 🦫🍊 וגמלים חגיגיים 🐪.

האתר מעוצב בגווני פסטל חמימים (שמנת, אפרסק, מנטה), פונטים עגולים בעברית (`Varela Round` ו-`Rubik`), אנימציות קופצניות ופיצ'רים אינטראקטיביים.
מוכן לפריסה סטטית ב-**GitHub Pages**.

---

## 🌸 פיצ'רים מרכזיים

1. **פתיח חגיגי ומקפיץ:**
   - שלישיית חיות מתוקות קופצות (כבשה, קפיברה עם תפוז, גמל).
   - כותרת גדולה בעברית עם אנימציות.
   - רקע נעים עם עננים צפים וחיות מרחפות בעדינות.

2. **מכתב אהבה מהלב 💌:**
   - כרטיס רך עם טקסט אישי, חם, רומנטי ומצחיק שמסביר כמה היא מושלמת.

3. **כרטיס כניסה חמוד ב-3D (הכרטיס הרשמי 🎟️):**
   - אפקט תלת-ממד שמגיב להזזת העכבר או למגע בטלפון.
   - פרטי הערב (תאריך, שעה, קוד לבוש "לוק חמוד שמאפשר לאכול בלי חשבון", והיעד הסודי של הגמל).
   - **כפתור אישור הגעה ("ברור שאני באה! 💖"):** מפעיל קונפטי צבעוני, נועל את המקום, ומאפשר הורדת קובץ יומן לטלפון (.ics) או הוספה בלחיצה ל-Google Calendar.
   - **כפתור סירוב מתחמק ("אממ... לא מתאים לי 🙄"):** בורח מהעכבר ומציג משפטים מצחיקים ("הקפיברה הטילה וטו", "הגמל ירק על הכפתור", "שגיאה 404: אי אפשר לסרב לדייט איתי").

4. **כרטיס גירוד סודי של הקפיברה 🐾:**
   - שכבת גירוד חמודה בקנבס HTML5.
   - גילוי של הרמז לארוחה ולקינוחים המושחתים עם האצבע במסך המגע או בעכבר.
   - ב-40% גירוד מתפוצץ קונפטי והרמז נחשף במלואו, עם אפשרות לגרד שוב!

5. **הלו״ז החגיגי של יום ההולדת ⏰:**
   - ציר זמן עם אייקונים של כבשה, קפיברה וגמל.
   - תחנות פתוחות מול הפתעה נעולה עם טיימר חי לאחור בעברית ("נפתח בעוד: ימים, שעות, דקות, שניות").

## 🚀 הרצה מקומית ופריסה

```bash
# התקנת תלויות
npm install

# הפעלת שרת פיתוח מקומי
npm run dev

# בנייה לפרודקשן
npm run build
```

לפריסה ב-GitHub Pages, כל מה שצריך זה לדחוף ל-GitHub ולבחור בהגדרות ה-Pages של הריפוזיטורי את **GitHub Actions**. הקובץ [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) כבר מוגדר ומטפל בהכל אוטומטית!
